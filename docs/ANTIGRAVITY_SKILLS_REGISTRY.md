## 3. Governance & Startup Execution Checklist
Every execution turn begins with the 8-step protocol:
1. Locate `.agents/skills/`.
2. Discover all 44 `SKILL.md` files.
3. Read complete instructions of every skill.
4. Inspect supporting references.
5. Identify applicable guidance.
6. Reconcile overlapping or conflicting instructions according to conflict hierarchy.
7. Formulate verified engineering plan.
8. Execute incrementally in small verified slices.

---

## 4. Conflict Resolution & Precedence Hierarchy
When instructions or recommendations from multiple specialist skills appear to diverge, the following strict hierarchy governs:
1. **System & Security Mandates**: RLS transaction-local variable injection, cryptographic token comparison, DPDP Act privacy rules.
2. **Approved Product Requirements**: Scope approved in `docs/PRODUCT_REQUIREMENTS.md` (e.g., Phase 2 payments deferral, 4-tier plan matrix, multi-business support).
3. **Permanent Engineering Standards**: Rules in `AGENTS.md` (NPM exclusively, Brand only from config, zero dynamic hot path on `/p/[slug]`, decoupled worker container).
4. **Specialist Reconciliations**: Resolve trade-offs explicitly and record in `docs/DECISIONS.md`.
